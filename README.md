## Setup

1. Clone the repository.
2. Run:

   npm install

3. Copy `.env.example` to `.env`.
4. Update the database settings in `.env`.
5. Run the SQL files inside `db/sql` in numerical order.
6. Start the application with:

   npm run dev

7. Open:

   http://localhost:3000
